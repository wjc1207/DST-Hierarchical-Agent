# 伙伴动作迁移：0.2.0

本批接通装备、砍树、挖矿、普通配方查询／制作和陆地放置。任务仍使用共用优先级看板；`companion_tasks.py` 将目标转为服务端动作，`jev_companion_actions.lua` 使用伙伴自己的原版组件执行。

| 目标／动作 | 行为与确认 |
|---|---|
| `inventory {prefab,count,allow_search?}` | 优先拾取附近产物，再采集／砍树／挖矿；没有来源时默认局部搜索，可设置 `allow_search:false`。达到伙伴背包总量才完成 |
| `visit_building {building_id}` | 返回已见建筑，允许远距离原生寻路，实际进入 3 单位内并刷新科技后完成 |
| `unequip {prefab}` | 将当前装备的该物品收回主物品栏／穿戴背包；检查实际收纳与装备状态，背包满或不允许卸下时说明原因 |
| `inventory {prefab,count,recipe_id}` | 按查到的普通配方制作，库存实际增加才算动作成功，按真实输出数量推进 |
| `equip {prefab}` | 装备伙伴携带且可用的物品；装备栏实际改变后完成 |
| `structure {prefab,recipe_id,x,z,radius?}` | 在中心附近选择合法陆地，观察到对应区域内的建筑后完成 |
| 原生 `work {target_guid,work}` | CHOP／MINE，每次推进真实工作量；掉落物另行拾取 |
| 原生 `craft {recipe_id}` | 使用伙伴材料、已学配方和当前科技，不调用控制台、不生成免费物品 |
| 原生 `place {recipe_id,x,z,radius?}` | 中心在伙伴附近 12 单位内，半径 2–8（默认 6），候选点距伙伴最多 20，重查游戏原生放置条件 |

砍树仅接入常见常青树、桦树、树枝树等；挖矿接入普通石矿、金矿、无燧石矿与冰矿。不把建筑或其他任意 workable 实体作为矿物目标。已有合适工具时会先装备；缺少工具时要求 DS 规划前置条件，不凭空执行工作。

## 配方查询

模型的 `query_recipes` 经本机 MCP `buddy_recipes` 查询当前绑定伙伴的服务端配方；复用公共查询参数和模型工具描述，支持 ID、产物、本地化名字、分页。查询只读，不会替玩家或伙伴制作。

返回材料、携带量、缺口、科技、已学／可原型制作状态、支持范围和当前可行性。无材料或缺科技的普通配方可作为有前置依赖的未来目标，执行时再次检查。使用实际产物 ID，例如科学机器为 `researchlab`，不使用旧客户端别名 `sciencemachine`。

需要绳子、木板、石砖等中间材料时，DS 显式规划；没有自动递归制作所有原料的求解器。特殊角色消耗、科技材料、皮肤专属、制造站和特殊水上放置等配方暂不执行，返回不支持原因。

服务端只持续回传基础及查询过的配方，监视集合最多 48 项；配方快照约 24 KB、单次查询约 16 KB 的编码预算。查询按实际返回位置继续分页，不在每帧扫描和传输全部制作表。

## 调度、完成与中断

共用看板保留优先级、依赖、专注、定时开始和真实进度。采集木头等目标会依次选择装备、工作、拾取；工作动作成功本身不算已经取得木头。矿物目标同理。制作配方 ID、产物和放置类型必须相符。

建筑目标的完成有空间约束，远处已有同类建筑不能完成当前区域目标；单次放置动作需要原生成功且看到新的实体。服务端每次重新核验归属、指令版本、材料、工具、目标和位置，RPC 重发不重复制作，新消息可停止旧动作。

前置条件不满足时重新规划，重复无进展有上限；附近没有目标资源时默认[局部搜索](COMPANION_PERCEPTION.md)，未开启搜索或没有安全的新落点时解释限制并归队。查询和制作都不读取主人的背包，也不会解锁超出游戏允许的科技。

## 实测

安装新版伙伴模组后重进世界，重启本机 `python mcp_agent/companion_agent.py --execute`，用 `/buddy summon` 绑定伙伴。可依次测试：

```text
/buddy do 做一把斧头，砍树收集3个木头，然后回来
/buddy do 做一把鹤嘴锄，挖矿收集3个石头，然后回来
/buddy do 在我附近建造一台科学机器
/buddy do 到科学机器旁边制作一块木板和一根绳子
```

需要附近实际可见的资源／建筑及所需材料。执行中再发 `/buddy do 先停下，回来` 验证中断。

箱子和烹饪锅本体可按普通配方建造；0.4.0 增加[物品交接和箱子查存取](COMPANION_STORAGE.md)。烹饪交互、设置家／驻留、全图探索、主动点火和完整夜间／战斗／生存策略仍未迁移。伙伴存档与跨洞迁移仍沿用当前原型限制。
